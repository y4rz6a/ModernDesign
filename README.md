# Y4rz6a - Premium Web Design

A modern, single-page portfolio website designed for high-end digital experiences. This project showcases advanced CSS animations, responsive layout engineering, and interactive UI elements.

## Overview

This portfolio is built with a focus on visual excellence and performance. It features a dark-themed aesthetic with neon accents, dynamic 3D elements, and smooth scroll-based animations.

## Features

- **Advanced CSS 3D Animations:** Custom rotating orb and cube components utilizing CSS `transform` and `perspective`.
- **Interactive UI:** Mouse-based parallax effects on typography and smooth scroll navigation.
- **Glassmorphism Design:** Utilization of `backdrop-filter` for modern, frosted-glass visual elements.
- **Scroll Reveal Animations:** Implemented via `IntersectionObserver` for optimized performance and subtle element fade-ins.
- **Fully Responsive:** Fluid layout adapting seamlessly across mobile, tablet, and desktop viewports.
- **Performance Focused:** Lightweight architecture using Vanilla JavaScript and Tailwind CSS (via CDN).

## Tech Stack

- **HTML5**
- **CSS3** (Custom properties, Keyframes, 3D Transforms)
- **Tailwind CSS** (Utility-first styling)
- **Vanilla JavaScript** (DOM manipulation, Event listeners)
